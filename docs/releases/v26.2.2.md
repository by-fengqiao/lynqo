# LanNook v26.2.2 — 传输可靠性与授权体验 / Transfer reliability and authorization

## 中文

### 新增

- 桌面系统通知：传输开始、完成、失败时弹出通知；托盘提示显示当前活跃传输任务数。
- 传输中心支持按文件名或设备搜索历史记录，并可多选批量重试、批量删除记录（磁盘上的已收文件保留）。
- 新设备授权时可指定时长（直到服务关闭 / 1 小时 / 24 小时 / 7 天），到期自动撤销；设置页可配置默认授权时长，设备页显示授权剩余时间。
- SHA-256 校验进度实时显示：传输完成后校验大文件时，进度条与详情面板会同步百分比。
- 上传断网自动重试：网络中断时自动从断点续传（最多重试 2 次），界面提示“网络中断，自动重试中…”。

### 改进

- 速度与剩余时间改用 EMA 平滑计算（收发两端一致），不再因分块边界抖动或瞬时归零。
- 失败的上传/下载任务可直接“继续”，从已完成分块处恢复，无需从头开始。

### 升级

这是 `v26.2.1` 的增量版本。已安装 `v26.2.1` 的用户应通过安装包或自动更新升级到 `v26.2.2`。

## English

### Added

- Desktop notifications for transfer start, completion, and failure; the tray tooltip shows the number of active transfers.
- Transfer Center now supports searching history by file name or device, plus multi-select batch retry and batch delete (files already received on disk are kept).
- Device approvals can carry an expiry (until the service closes / 1 hour / 24 hours / 7 days) and are revoked automatically; the default duration is configurable in Settings, and the Devices page shows remaining authorization time.
- Real-time SHA-256 verification progress: after a transfer completes, large-file checks update the progress bar and detail panel with a live percentage.
- Automatic upload retry after network drops: the transfer resumes from its chunk checkpoint (up to 2 retries) with an “auto-retrying” indicator.

### Improved

- Speed and remaining-time telemetry now use EMA smoothing on both ends, eliminating chunk-boundary jitter and spurious zero readings.
- Failed transfers can be resumed directly, continuing from completed chunks instead of restarting.

### Upgrade

This is an incremental release for `v26.2.1`. Existing `v26.2.1` installations should update to `v26.2.2` through the installer or automatic updater.
