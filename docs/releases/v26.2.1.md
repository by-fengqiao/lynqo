# LanNook v26.2.1 — 品牌与连接体验修复 / Brand and connection UX fixes

## 中文

### 修复

- 顶部栏、移动端顶部栏和“关于”页统一显示 LanNook，不再残留旧品牌字样。
- 连接网络地址时，Windows 防火墙诊断使用无窗口模式，不再闪出 PowerShell 控制台。
- 连接面板的后台网络检测不会清空或重绘未变化的二维码；只有网络地址、端口或配对令牌变化时才会生成新二维码。

### 升级

这是 `v26.2.0` 的补丁版本。已安装 `v26.2.0` 的用户应安装或通过自动更新升级到 `v26.2.1`。

## English

### Fixed

- The desktop header, mobile header, and About page consistently display LanNook with no remaining legacy product label.
- Windows firewall inspection runs without a visible PowerShell window when a connection address is selected.
- Background network checks keep an unchanged QR code in place. A new QR image is generated only when the address, port, or pairing token changes.

### Upgrade

This is a patch release for `v26.2.0`. Existing `v26.2.0` installations should update to `v26.2.1` through the installer or automatic updater.
