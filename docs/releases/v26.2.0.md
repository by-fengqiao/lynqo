# LanNook v26.2.0 — 品牌迁移与兼容更新 / Brand Migration and Compatibility Update

## 中文

LYNQO 自本版本起更名为 **LanNook**。项目的局域网传输定位、GPL-3.0-only 许可证和既有功能保持不变；本次重点是让已安装用户能够平滑升级，而不是要求重新安装或重新配对。

### 变化

- 应用名称、窗口标题、系统托盘、诊断报告、帮助与法律文档统一使用 LanNook。
- npm/Cargo 包名、构建产物和后续 Release 资产改用 `lannook` / `LanNook`。
- mDNS 服务类型更新为 `_lannook._tcp.local.`，新的 Windows 防火墙规则命名为 `LanNook LAN File Transfer`。
- 更新地址、README、贡献指南、博客源文档和 GitHub 链接指向新仓库名称。

### 兼容与迁移

- 自动迁移旧 `LYNQO` 数据目录中的数据库、设置和日志到 `LanNook`。
- 自动复制旧浏览器语言、协议确认、首次引导和手机稳定 ID 到新的 `lannook.*` 存储键。
- 继续识别旧的 LYNQO Windows 防火墙规则。
- 为保证 v26.1.7 能原地升级，桌面包标识 `com.lynqo.desktop` 暂时保留为兼容层；它不再对用户展示。

完整迁移细节见 [LYNQO → LanNook 迁移说明](../migrations/lynqo-to-lannook.md)。

## English

Beginning with this version, **LYNQO is renamed LanNook**. Its local-network focus, GPL-3.0-only license, and existing functionality remain unchanged. The goal is a smooth upgrade for installed users, not a clean reinstall or new device pairing.

### Changes

- The application name, window title, tray, diagnostics, help, and legal documents now use LanNook.
- npm/Cargo package names, build output, and future Release assets use `lannook` / `LanNook`.
- The mDNS service type is now `_lannook._tcp.local.` and new Windows Firewall rules use `LanNook LAN File Transfer`.
- Updater endpoints, README files, contribution guides, blog source, and GitHub links target the new repository name.

### Compatibility and migration

- Existing `LYNQO` databases, settings, and logs migrate automatically into the `LanNook` data directory.
- Browser language, legal acknowledgement, onboarding, and mobile stable IDs are copied into `lannook.*` keys.
- Existing LYNQO Windows Firewall rules remain recognized.
- The desktop bundle identifier `com.lynqo.desktop` remains temporarily for v26.1.7 in-place update compatibility; it is no longer user-facing.

See [LYNQO to LanNook migration](../migrations/lynqo-to-lannook.md) for the full migration behavior.
